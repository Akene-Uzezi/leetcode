# LeetCode Solutions

A collection of LeetCode problem solutions implemented in Go.

## Structure

Each problem has its own directory containing a standalone `main.go` file with the solution.

## Problems

- `first-palindromic-string-in-array` - Find the first palindromic string in an array
- `valid-palindrome` - Check if a string is a valid palindrome (ignoring non-alphanumeric characters and case)
- `move-zeros-back` - Move all zeros in an integer array to the end while maintaining the relative order of non-zero elements
- `apply-operations-to-an-array` - Apply operations to an array where adjacent equal elements are doubled and set to zero
- `removeduplicates` - Remove duplicates from a sorted array in-place and return the new length

## Running

Navigate to any problem directory and run:

```bash
go run main.go
```
